# Credibility Criteria

Verify candidates before ranking them.

## Required checks

| Check | Question |
| --- | --- |
| Existence | Does the resource exist at a canonical or authoritative location? |
| Identity | Are title, creator, institution, edition, and date accurate? |
| Relevance | Does it directly serve the confirmed goal and scope? |
| Authority | Does the creator have relevant expertise or institutional responsibility? |
| Evidence | Are claims sourced, reviewed, documented, or supported by primary evidence? |
| Currency | Is it current enough for this topic? |
| Access | Can the user obtain it in the required language, budget, and region? |
| Fit | Is the level and format appropriate? |
| Independence | Are commercial, ideological, or institutional conflicts visible? |

## Ranking dimensions

Score qualitatively or numerically:

- authority;
- relevance;
- accessibility;
- timeliness;
- depth;
- practicality;
- reliability;
- complementarity.

Do not collapse all dimensions into one opaque score. Explain the decisive trade-offs.

## Citation record

Capture when available:

- canonical title;
- author, creator, or institution;
- resource type;
- publication or update date;
- edition or version;
- canonical URL;
- access date for changing pages;
- access conditions;
- verification note.

## Conflict handling

- Separate primary evidence from later interpretation.
- Describe credible disagreement and its basis.
- State when evidence is incomplete, inaccessible, or disputed.
- Avoid false balance when one position lacks credible support.
- Avoid treating popularity, search ranking, or follower count as authority.

## Exclusion triggers

Exclude or clearly quarantine a resource when it is fabricated, misattributed, inaccessible without disclosure, materially outdated, irrelevant, plagiarized, unsupported, or primarily promotional without independent value.
