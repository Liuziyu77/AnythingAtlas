# Roadmap Schema

Turn the atlas into an executable sequence.

## Stage contract

Every stage must contain:

| Field | Requirement |
| --- | --- |
| Title | Name the capability or understanding gained |
| Duration | Give elapsed time and suggested weekly effort |
| Objectives | Use observable outcomes |
| Prerequisites | Name dependencies or write “None” |
| Resources | Assign exact resources and relevant portions |
| Tasks | Specify reading, watching, analysis, practice, or building |
| Deliverable | Produce something inspectable |
| Completion criteria | Define evidence of readiness |
| Self-check | Include questions, exercises, explanation, or reproduction |
| Optional branches | Separate enrichment from the core path |

## Sequencing rules

- Teach prerequisites before dependent concepts.
- Alternate consumption with recall, application, or synthesis.
- Introduce primary evidence when the user can interpret it.
- Keep each stage small enough to complete.
- Reserve buffer time for review and slippage.
- Mark skippable material.
- End every stage with a checkpoint.
- End the roadmap with a capstone or synthesis outcome when appropriate.

## Time adaptation

| Available time | Recommended shape |
| --- | --- |
| A few hours | Orientation, one core resource, one verification task |
| 1–2 weeks | Foundation plus one guided exercise |
| 1–3 months | Multi-stage curriculum with a project or synthesis |
| 3–12 months | Foundations, specialization, practice, and capstone |
| Open-ended | Core path plus modular deeper branches and update channels |

## Resource assignment

Do not write “read this book” without scope. Assign chapters, sections, lectures, or a stopping point whenever possible.

Do not overload a stage. Prefer one primary resource plus complementary evidence or practice.

## Completion examples

Use observable checks such as:

- explain the concept without notes;
- compare two frameworks with evidence;
- reproduce a result;
- solve a representative problem;
- annotate a primary source;
- build a small project;
- write a synthesis memo;
- pass a self-designed quiz with explicit criteria.
